Cryptographic Architecture & Live Self-Test

Auditable Web Crypto API (window.crypto.subtle) Verification

1. Key Derivation (PBKDF2)

PBKDF2-HMAC-SHA256 with 600,000 iterations and a 16-byte random salt derives a 256-bit Key-Encryption-Key (KEK).

2. Envelope Key Wrapping

Every item/file generates a unique 256-bit AES-GCM Data Key wrapped by the Master Key with a fresh 12-byte IV.

3. 4 MB Stream Chunking

Large files are sliced into 4,194,304-byte chunks; each chunk is encrypted with its own random 12-byte IV & 128-bit GCM auth tag.

4. Dual Recovery Key Wrapping

A 256-bit CSPRNG Recovery Key wraps a second copy of the Master Key so password loss does not lose data.
